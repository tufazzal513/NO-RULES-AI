# 🐣 বিগিনার গাইড — নিজের AI ট্রেন করুন (সম্পূর্ণ ফ্রি)

একদম নতুন? চিন্তা নেই। **একটা সেল কপি করে Colab-এ পেস্ট করে Run চাপবেন — ব্যস।**
বাকি সব (ডাটা নামানো, মিশানো, ট্রেনিং, GGUF বানানো, zip নামানো) নিজে থেকেই হবে।

> ⏱️ আপনার হাতের কাজ: **~৫ মিনিট** · ট্রেনিং অটো চলে: **১–৫ ঘণ্টা**
> 💰 খরচ: **০ টাকা** (Google Colab-এর ফ্রি T4 GPU)

## ধাপ ১ — Colab খুলুন (২ মিনিট)

1. [colab.research.google.com](https://colab.research.google.com) → **File → New notebook**
2. **Runtime → Change runtime type → T4 GPU → Save**
3. **Connect** চাপুন — ডানদিকে সবুজ ✓ আর RAM/Disk মিটার দেখলে OK

> নোটবুক আপলোড করতে চাইলে: রিপোর `training/colab_bangla_english.ipynb` ফাইলটা
> **File → Upload notebook** দিয়ে দিন। ভেতরে একটাই সেল থাকবে।

## ধাপ ২ — সেলটা পেস্ট করে Run দিন (১ মিনিট)

রিপোর [`training/colab_one_click.py`](./colab_one_click.py) ফাইলের **পুরো কোডটা** কপি করে
Colab-এর সেলে পেস্ট করুন, তারপর ▶ **Run**।

উপরের দিকে শুধু এই কয়টা লাইন চাইলে বদলাতে পারেন:

```python
PLAN  = 'balanced'   # basic (দ্রুত) | balanced (সুপারিশ) | advanced (রিজনিং বেশি)
HOURS = 5            # কত ঘণ্টা ট্রেন হবে — ১ / ৩ / ৫
MODEL = 'unsloth/Qwen2.5-1.5B-Instruct'   # শক্তিশালী চাইলে: Qwen2.5-3B-Instruct
OWNER_NAME = ''      # আপনার নাম — মডেল আপনার নাম জানবে
```

Run চাপার পর:

1. **ফাইল আপলোডের বক্স আসবে** — নিজের `myai-dataset.jsonl` থাকলে দিন,
   না থাকলে **Cancel** চাপুন (ডিফল্ট ডাটাতেই ভালো কাজ করবে)
2. **Google Drive-এর অনুমতি চাইবে** — অবশ্যই **Allow** দিন
   (তাহলে ডিসকানেক্ট হলেও checkpoint বেঁচে থাকবে)
3. এরপর আর কিছু করার নেই — লগ দেখতে থাকুন

> 📡 **কন্ট্রোল প্যানেলে লাইভ দেখতে চান?** MY-AI প্যানেলের **Training** ট্যাবে
> **“Copy Colab cell”** চাপুন — ওখান থেকে কপি করা সেলে `PANEL_URL` আর
> `PANEL_TOKEN` আগে থেকেই বসানো থাকে। তখন step, loss, ETA সব প্যানেলেই দেখবেন।

## 🔴 ডিসকানেক্ট হয়ে গেছে?

**ভয় নেই — কিছুই হারায়নি।** Drive-এ প্রতি কিছুক্ষণ পরপর checkpoint সেভ হচ্ছিল।

1. **Connect** চাপুন
2. **একই সেলটা আবার Run দিন**
3. লগে `↩️ Resuming from …/checkpoint-XXX` দেখবেন — শেষ জায়গা থেকেই চলবে

ডাটাও আবার নামবে না (`✅ রেডিমেড ডাটা আছে — ডাউনলোড স্কিপ`)।

## 🛟 সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| `CUDA out of memory` | **নিজে থেকেই ঠিক হয়ে যায়** — স্ক্রিপ্ট eval বন্ধ → batch ১ → packing বন্ধ → ছোট seq করে checkpoint থেকে আবার চালু করে। তবু না হলে `MODEL = 'unsloth/Qwen2.5-0.5B-Instruct'` |
| সেশন হঠাৎ মরে যায় / `exit -9` | RAM শেষ। স্ক্রিপ্ট নিজেই হালকা সেটিংসে ৩ বার পর্যন্ত আবার চালায়; না হলে `HOURS = 1` করুন |
| `🚨 রিপোতে অ্যাক্সেস হচ্ছে না` | রিপোটা private — GitHub → Settings → General → Danger Zone → **Change to public** |
| `pip install`-এ এরর | সেলটা আবার Run দিন (Colab-এ মাঝে মাঝে হয়) |
| Colab-এর GPU লিমিট শেষ / RAM বারবার শেষ হচ্ছে | [Kaggle](https://kaggle.com) ব্যবহার করুন — RAM ~২৯–৩২ GB (Colab-এর ১২.৭ GB-র বদলে), সপ্তাহে ~৩০ ঘণ্টা ফ্রি GPU। পুরো ধাপে ধাপে: [`KAGGLE_GUIDE_BN.md`](./KAGGLE_GUIDE_BN.md) |

## ধাপ ৪ — মডেল চালান (Ollama)

1. [ollama.com](https://ollama.com) থেকে **Ollama** ইনস্টল করুন (Windows/Mac/Linux)
2. নামানো `my-ai-model.zip` আনজিপ করে সেই ফোল্ডারে টার্মিনাল খুলুন:

```bash
ollama create my-ai -f Modelfile
ollama run my-ai
```

3. বাংলায় লিখে দেখুন — উত্তরও বাংলায় আসবে!

## ধাপ ৫ — MY-AI-এর সাথে যুক্ত করুন

MY-AI-এর `.env` ফাইলে:

```env
ACTIVE_MODEL=ollama:my-ai
MODEL_PATH=http://localhost:11434
```

Ollama ব্যাকগ্রাউন্ডে চালু থাকলে MY-AI এবার আপনার ট্রেন করা মডেল দিয়ে উত্তর দেবে।

## ❓ সাধারণ প্রশ্ন

**মডেল কি নতুন তথ্য শিখবে?**
না। ফাইন-টিউনিং আপনার **ঢং আর ভাষা** শেখায়, নতুন **ফ্যাক্ট** নয়। নিজের ডকুমেন্ট থেকে
সঠিক উত্তর চাইলে MY-AI-এর **Knowledge ট্যাব (RAG)** ব্যবহার করুন — ট্রেনিং ছাড়াই কাজ করে।
সবচেয়ে ভালো ফল = ট্রেন করা মডেল **+** Knowledge ট্যাব, দুটো একসাথে।

**৩ ঘণ্টা না ৫ ঘণ্টা?**
৫ ঘণ্টায় মডেল বেশি ডাটা দেখে, উত্তর ভালো হয়। Colab ফ্রি-তে ৫ ঘণ্টা টানা পাওয়া
কঠিন — তবে ডিসকানেক্ট হলে resume আছে, তাই ভয় নেই।

**আরও ভালো মডেল চাই?**
`MODEL = 'unsloth/Qwen2.5-3B-Instruct'` দিন। স্ক্রিপ্ট নিজেই batch/seq কমিয়ে
T4-তে ফিট করিয়ে নেবে (একটু ধীরে চলবে)।
