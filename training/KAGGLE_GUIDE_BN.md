# 🎮 Kaggle গাইড — MY-AI ট্রেন করুন সম্পূর্ণ ফ্রি (বাংলায় ধাপে ধাপে)

Colab-এর GPU লিমিট শেষ? ডিসকানেক্টের জ্বালায় অতিষ্ঠ? **Kaggle**-এ একই
`kaggle_one_click.py` স্ক্রিপ্ট চালিয়ে MY-AI-কে বাংলা+ইংরেজি ট্রেন করান —
সপ্তাহে ~৩০ ঘণ্টা ফ্রি GPU, আর **RAM প্রায় দ্বিগুণেরও বেশি**।

> ⏱️ আপনার হাতের কাজ: **~১০ মিনিট** (একবারই) · ট্রেনিং অটো চলে: **১–৫ ঘণ্টা**
> 💰 খরচ: **০ টাকা** · 🧠 GPU: **T4 ×2** (প্রতিটা 16 GB VRAM) বা P100
> 📖 আরও গাইড: [`README.md`](./README.md) · [`BEGINNER_GUIDE_BN.md`](./BEGINNER_GUIDE_BN.md)

## Colab vs Kaggle — কোনটা কখন?

| বিষয় | Google Colab (ফ্রি) | Kaggle (ফ্রি) |
|---|---|---|
| **সিস্টেম RAM** | **~১২.৭ GB** | **~২৯–৩২ GB** (আগে ২৯ GB ছিল, এখন ~৩২) |
| GPU | ১টা T4 (16 GB) | T4 ×2 (১৬+১৬ GB) বা P100 (16 GB) |
| সাপ্তাহিক GPU কোটা | হিসাব-নিকাশ নেই — "ব্যবহার" দেখে কাটে | **~৩০ ঘণ্টা/সপ্তাহ**, পরিষ্কার মিটার |
| একটা সেশন কতক্ষণ | ১২ ঘণ্টা পর্যন্ত বলা আছে, কিন্তু ডিসকানেক্ট খুব কমন | **~৯–১২ ঘণ্টা** (GPU) — তারপর নিজে থামে |
| স্টোরেজ | কিছুই বাঁচে না (Drive mount করলে চলে) | **~২০ GB** — Output ট্যাবে zip বেঁচে থাকে |
| ব্যাকগ্রাউন্ড রান | নেই (কিছু ট্রিক ছাড়া) | ✅ **Save & Run All (Commit)** — ব্রাউজার বন্ধ করলেও চলে |

🔑 **আমাদের জন্য আসল পার্থক্যটা RAM।** MY-AI ট্রেনিংয়ে এ পর্যন্ত যে OOM
হয়েছে, তার বেশিরভাগই ছিল **সিস্টেম RAM শেষ হয়ে যাওয়া** (ডাটা-পুল বড় হলে
Colab-এর ১২.৭ GB-তে টেকেনি, প্রসেস `exit 137` দিয়ে মরেছে)। Kaggle-এর ~২৯–৩২ GB
RAM-তে সেই সমস্যা কার্যত নেই — তাই বড় ডাটা-পুল (ROWS) নিয়েও আরামে চলে।

> 💡 Kaggle-এ RAM > ১৪ GB হওয়ায় স্ক্রিপ্টের **অটো রো-ক্যাপও লাগে না** —
> Colab-এ RAM কম দেখে স্ক্রিপ্ট নিজেই ডাটা-পুল ছোট করে দিত, Kaggle-এ পুরো পুলই ব্যবহার হবে।

## ⚠️ প্রথমেই জেনে নিন (সবচেয়ে গুরুত্বপূর্ণ সত্য)

**Kaggle নিজে থেকে চলতে থাকে না — যতক্ষণ না আপনি "Commit" করেন।**

- **Interactive সেশন** (সাধারণভাবে নোটবুক খুলে Run চাপলে): ট্যাব বন্ধ করলে
  বা **২০–৪০ মিনিট নিষ্ক্রিয় (idle) থাকলে সেশন মেরে দেওয়া হয়**। এভাবে
  ৫ ঘণ্টার ট্রেনিং চালিয়ে ঘুমাতে গেলে সব হারাবেন।
- **ব্যাকগ্রাউন্ডে চলে শুধু একভাবে:** উপরে **Save Version → Save & Run All (Commit)**
  চাপলে। তখন Kaggle তার নিজের সার্ভারে কোড চালায় — আপনার ট্যাব বন্ধ করলেও,
  ইন্টারনেট কেটে গেলেও, ল্যাপটপ বন্ধ করলেও **ট্রেনিং চলতে থাকে** এবং শেষে
  আউটপুট (zip) নোটবুকের **Output ট্যাবে জমা থাকে**।

> তাই নিয়ম একটাই: **ছোট পরীক্ষা → normal Run। আসল ট্রেনিং → Save & Run All (Commit)।**

## ধাপ ১ — অ্যাকাউন্ট খুলে ফোন ভেরিফাই করুন (৫ মিনিট, একবারই)

1. [kaggle.com](https://www.kaggle.com) → **Register** (Google/GitHub দিয়েও হয়)
2. **ফোন নম্বর ভেরিফাই করা বাধ্যতামূলক** — না করলে GPU-এর অপশন **ধূসর (disabled)**
   থাকবে। Kaggle মাঝে মাঝে মোবাইলে কোড পাঠায়, সেটা বসান।
   (ভেরিফাই করতে: উপরে ডানে প্রোফাইল → **Settings** → **Phone Verification**)
3. এরপর ডানদিকের মেনুতে গিয়ে **GPU Quota**-তে "30h / week" দেখতে পাবেন।

## ধাপ ২ — নোটবুক বানিয়ে সেটিংস দিন (২ মিনিট)

1. বাঁ পাশে **Create → New Notebook** (বা `kaggle.com/code` → New Notebook)
2. ডান পাশে **Settings** প্যানেল খুলুন:

   | সেটিং | মান | কেন |
   |---|---|---|
   | **Accelerator** | **GPU T4 x2** (বা P100) | T4 x2 সবচেয়ে স্থিতিশীল; স্ক্রিপ্ট একটা GPU-তেই ট্রেন করে |
   | **Internet** | **ON** 🔴 | OFF থাকলে HF ডাটা আর রিপোর ফাইল **নামতেই পারবে না** |
   | Persistence | চাইলে "Files only" | আউটপুট/checkpoint ফাইলের জন্য (ঐচ্ছিক) |

3. **Turn on GPU** ক্লিক করে সেশন চালু করুন

## ধাপ ৩ — কোড বসান (১ মিনিট)

দুটো পদ্ধতির যেকোনো একটা:

**পদ্ধতি A — প্যানেল থেকে (সেরা):** MY-AI কন্ট্রোল প্যানেলের **Training** ট্যাবে
**"Copy Kaggle cell"** চাপুন। ওই সেলে আপনার প্যানেলের URL আর অ্যাডমিন টোকেন
আগে থেকেই বসানো থাকে (`MYAI_PANEL_URL` / `MYAI_ADMIN_TOKEN` env-ভ্যারিয়েবল দিয়ে,
তাই উদ্ধৃতি-চিহ্নের সমস্যা হয় না)। সেলটা পেস্ট করে দিন।

**পদ্ধতি B — সরাসরি:** রিপোর [`kaggle_one_click.py`](./kaggle_one_click.py)-এর পুরো
কোড কপি করে সেলে পেস্ট করুন। তারপর উপরের সেটিংস লাইনগুলো চাইলে বদলান:

```python
PLAN  = 'balanced'   # basic | balanced | advanced
HOURS = 5            # 1 / 3 / 5 ঘণ্টা — কোটা বাঁচাতে 5 দিলে ৫ ঘণ্টাই খরচ হবে
MODEL = 'unsloth/Qwen2.5-1.5B-Instruct'
OWNER_NAME = ''      # আপনার নাম
```

> স্ক্রিপ্টের ওপরের `PLAN`, `HOURS` ইত্যাদি **খালি/ডিফল্ট থাকলে** `MYAI_*`
> এনভায়রনমেন্ট ভ্যারিয়েবল (বা Secrets) থেকে মান নেবে — খালি না থাকলে
> সেটিংসের মানই প্রাধান্য পাবে। দুটো জায়গাতেই না থাকলে ডিফল্ট চলবে।

## ধাপ ৪ — (ঐচ্ছিক) নিজের ডাটা দিন

প্যানেল থেকে এক্সপোর্ট করা `myai-dataset.jsonl` বা নিজের যেকোনো `.jsonl`:

1. নোটবুকের ডান পাশে **+ Add Input → Upload → New Dataset**
2. ফাইল টেনে ছাড়ুন → **Create** করুন
3. ব্যস! স্ক্রিপ্ট নিজেই `/kaggle/input`-এর **সব `.jsonl`** খুঁজে নিয়ে
   ট্রেনিং ডাটায় মিশিয়ে দেবে — কোনো কোড বদলাতে হবে না।

## ধাপ ৫ — (ঐচ্ছিক, সুপারিশকৃত) টোকেন Secrets-এ রাখুন

নোটবুকটা কখনো পাবলিক/শেয়ার করলে প্যানেলের অ্যাডমিন টোকেন যেন ফাঁস না হয়,
তাই টোকেনটা সেলে না লিখে **Secrets**-এ রাখুন:

1. ডান পাশে **Add-ons → Secrets** → Attach করুন
2. নতুন secret যোগ করুন:

   | Label | Value |
   |---|---|
   | `MYAI_PANEL_URL` | `https://no-rules-ai.onrender.com` |
   | `MYAI_ADMIN_TOKEN` | আপনার প্যানেলের ADMIN_PASSWORD |

3. স্ক্রিপ্ট `kaggle_secrets.UserSecretsClient()` দিয়ে এগুলো নিজেই পড়ে নেয় —
   সেলে আর কিছু লিখতে হবে না।

## ধাপ ৬ — আসল ট্রেনিং: Save & Run All (Commit) 🔴

ছোট টেস্ট হয়ে গেলে (লগে `✅ GPU OK` আর HF ডাউনলোড দেখা গেছে):

1. উপরে ডানে **Save Version → Save & Run All (Commit)** চাপুন
2. এখন **ট্যাব বন্ধ করে দিতে পারেন** — ট্রেনিং Kaggle-এর সার্ভারে চলবে
3. লাইভ দেখুন দুই জায়গায়:
   - **MY-AI প্যানেল → Training ট্যাব**: step, loss, ETA, VRAM সব লাইভ
     (স্ক্রিপ্ট প্রতি কয়েক সেকেন্ডে হার্টবিট পাঠায়)
   - `kaggle.com/kaggle/notebooks` → নোটবুকের status: **Running**

> ⏰ স্ক্রিপ্ট সময়-বাজেট ধরে চলে: `HOURS = 5` দিলে ঠিক ৫ ঘণ্টার মধ্যে শেষ করে
> মডেল সেভ করবে। সেশন লিমিট (~৯–১২ ঘণ্টা) বা সাপ্তাহিক কোটা (~৩০ ঘণ্টা) শেষ
> হওয়ার আগেই নিজে থেমে যাবে — তাই অর্ধেক কাজ হাতে মারাও যায় না।

## ধাপ ৭ — ফলাফল নামান

1. Commit-run শেষ হলে নোটবুকের **Output** ট্যাবে যান (`/edit` ছাড়া URL-এ)
2. **`my-ai-model.zip`** → Download
3. আনজিপ করে:

```bash
ollama create my-ai -f Modelfile
ollama run my-ai
```

তারপর MY-AI-এর `.env`-এ: `ACTIVE_MODEL=ollama:my-ai` + `MODEL_PATH=http://localhost:11434`

## 💡 কোটা-সীমার হিসাব (মনে রাখুন)

- **GPU কোটা: ~৩০ ঘণ্টা/সপ্তাহ** — রিসেট হয় সাপ্তাহিক। ডান পাশের মেনুর
  **GPU Quota**-য় কত খরচ হলো দেখা যায়। `HOURS = 5` মানে প্রতি রানে ৫ ঘণ্টা কাটবে।
- **সেশন লিমিট: ~৯–১২ ঘণ্টা** — তাই `HOURS` কখনো ৯-এর বেশি দেবেন না।
- **স্টোরেজ ~২০ GB** — /kaggle/working-এর আউটপুট বেঁচে থাকে; পুরনো রানের
  জমে থাকা ফাইল মুছে দিলে জায়গা ফেরে।
- **/kaggle/input পড়া যায়, লেখা যায় না** — সব আউটপুট /kaggle/working-এই যায়
  (স্ক্রিপ্ট নিজেই ওখানে সেভ করে)।

## 🛠️ ট্রাবলশুটিং

| সমস্যা | কারণ | সমাধান |
|---|---|---|
| Accelerator-এ GPU অপশন ধূসর | ফোন ভেরিফাই করা হয়নি | Settings → Phone Verification → কোড বসান |
| ডাটা/ফাইল ডাউনলোডে `❌` | Internet **OFF** | Settings → Internet → **ON** → আবার Run |
| ট্যাব বন্ধ করার পর ট্রেনিং মরে গেছে | Interactive সেশনে চালিয়েছিলেন | **Save & Run All (Commit)** দিয়ে চালান — এটাই ব্যাকগ্রাউন্ড রানের একমাত্র উপায় |
| ২০–৪০ মিনিটে সেশন "idle" হয়ে থেমে যায় | Interactive সেশন idle-out | আবার Save & Run All (Commit) — ব্যাকগ্রাউন্ড রানে idle-out নেই |
| `❌ রিপোতে অ্যাক্সেস হচ্ছে না!` | রিপো private | GitHub → NO-RULES-AI → Settings → Danger Zone → **Change to public** |
| GPU কোটা শেষ / "quota exhausted" | ৩০ ঘণ্টা/সপ্তাহ খরচ | কোটা রিসেট পর্যন্ত Colab ব্যবহার করুন, বা `HOURS = 1` করে ছোট রান দিন |
| RAM/OOM এখনো হচ্ছে | ডাটা-পুল অনেক বড় | স্ক্রিপ্ট নিজেই ৩ ধাপে হালকা করে (eval বন্ধ → batch ১ → ছোট seq); তবু হলে `MODEL = 'unsloth/Qwen2.5-0.5B-Instruct'` |
| Output ট্যাবে zip নেই | রানটা ব্যর্থ হয়েছিল | নোটবুকের Logs দেখুন → পুরো লাল অংশ কপি করে রাখুন |
| প্যানেলে লাইভ দেখতে পাচ্ছি না | PANEL_URL/TOKEN ভুল বা প্যানেল ঘুমিয়ে | সেলে `MYAI_PANEL_URL` সঠিক কিনা দেখুন; Render-এর ফ্রি টায়ার ঘুমালে ১–২ মিনিট অপেক্ষা করুন |
| নিজের .jsonl মেশেনি | Dataset ঠিকমতো add হয়নি | নোটবুকের Input তালিকায় dataset আছে কিনা দেখুন; স্ক্রিপ্ট `/kaggle/input/**/*.jsonl` সব নেয় |

**কিছুতেই না মিললে:** লগের পুরো লাল অংশ + স্ক্রিপ্টের প্রিন্ট করা error কপি করে
রাখুন এবং শেয়ার করুন — এগুলো ছাড়া দূর থেকে সমস্যা ধরা কঠিন।

## ❓ ছোট প্রশ্ন

**T4 x2 পাচ্ছি অথচ ট্রেনিং কি দুটো GPU-ই ব্যবহার করে?**
না — স্ক্রিপ্ট ইচ্ছা করেই `CUDA_VISIBLE_DEVICES=0` সেট করে একটা T4-তে চলে।
দুটো কার্ডে accelerate মডেল ভাগ করতে গিয়ে আগে অহেতুক OOM হয়েছে। একটা T4-তেই
১.৫B মডেলের LoRA আরামে চলে, আর তাতে VRAM-ও অর্ধেক খরচ হয় (কোটা গণনায় সুবিধা)।

**কোটা বাঁচানোর উপায়?**
হ্যাঁ: `HOURS = 1` দিয়ে টেস্ট রান দিন। রান শেষ হওয়ার আগেই থামাতে চাইলে
নোটবুক পেজে **Stop** চাপুন — সেটা অবধি খরচ হওয়া সময়ই কাটবে। স্ক্রিপ্ট
checkpoint সেভ করে, তাই পরের রানে `--resume`-এর মতোই আগের জায়গা থেকে চলে।

**Colab-এ চালানো সেলটা Kaggle-এ চালাব কী করে?**
চালাবেন না — প্ল্যাটফর্ম আলাদা। প্যানেলের **"Copy Kaggle cell"** বাটন ব্যবহার
করুন (Kaggle-এর স্ক্রিপ্ট), নয়তো `kaggle_one_click.py` কপি করুন।
