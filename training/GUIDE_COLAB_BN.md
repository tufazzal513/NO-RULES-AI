## ০. আগে বুঝে নিন — কী শিখবে, কী শিখবে না

| ✅ ফাইন-টিউনিং যা শেখায় | ❌ যা শেখায় না |

| বাংলা/ইংরেজি/বাংলিশে **স্বাভাবিকভাবে কথা বলা** | নতুন ফ্যাক্ট মুখস্থ করা |

## ১. কোন প্ল্যান আপনার জন্য?

নোটবুকের ধাপ ৬-এ ড্রপডাউন থেকে বেছে নিন:

| প্ল্যান | সময় | মডেল | ডাটা (আনুমানিক) | ফল |
|---|---|---|---|---|
| ⚡ **Quick** | ~১ ঘণ্টা | Qwen2.5-1.5B | ~৯ হাজার উদাহরণ | সালাম-আলাপ, সহজ প্রশ্নোত্তর, ছোট উত্তর |
| ⭐ **Balanced** (সুপারিশ) | ~৩ ঘণ্টা | Qwen2.5-1.5B | ~২৭ হাজার | কথাবার্তা + লেখা + অনুবাদ + কিছুটা রিজনিং |
| 🚀 **Advanced** | ~৫ ঘণ্টা | Qwen2.5-3B | ~৪৫ হাজার | লম্বা গোছানো উত্তর, রিজনিং, কোড |

**প্রথমবার হলে Quick দিয়ে শুরু করুন** — এক ঘণ্টায় পুরো প্রক্রিয়াটা চোখে দেখে
নিন, তারপর Balanced/Advanced চালান।

## ৪. কমান্ড লাইনেও চালানো যায়

নোটবুক ছাড়া (নিজের GPU/সার্ভারে) একই জিনিস:

```bash
pip install unsloth trl transformers datasets accelerate peft bitsandbytes

python train_lora.py \
    --model unsloth/Qwen2.5-1.5B-Instruct \
    --recipe balanced \
    --time-budget-hours 3 \
    --assistant-name "MY-AI" --owner-name "আপনার নাম" \
    --extra-jsonl myai-dataset.jsonl \
    --extra-jsonl ../data/import/bangla-english-banglish-chat.jsonl \
    --output ./my-ai-model \
    --export-gguf
```

### দরকারি অপশন

| অপশন | কাজ |
|---|---|
| `--time-budget-hours 3` | **কত ঘণ্টা ট্রেন হবে** — স্ক্রিপ্ট নিজেই স্টেপ হিসাব করে থামে |
| `--recipe basic\|balanced\|advanced` | ডাটা মিক্স ও কঠিনতার মাত্রা |
| `--rows 40000` | মিক্সে ঠিক কতগুলো উদাহরণ নেবে (বাজেটের হিসাব ওভাররাইড) |
| `--model …` | বেস মডেল (নিচের টেবিল দেখুন) |
| `--extra-jsonl file` | নিজের ডাটা (বারবার দেওয়া যায়, ফাইল না থাকলে স্কিপ) |
| `--resume` | শেষ চেকপয়েন্ট থেকে আবার শুরু |
| `--batch-size 1 --grad-accum 16` | GPU মেমোরি কম পড়লে |
| `--export-gguf` | Ollama-র জন্য GGUF + Modelfile |
| `--skip-tests` | শেষের টেস্ট প্রশ্নগুলো বাদ |
| `--max-steps 500` | সময়ের বদলে নির্দিষ্ট স্টেপ |
| `--time-budget-hours 0 --epochs 2` | পুরনো ধাঁচে epoch-ভিত্তিক ট্রেনিং |

### শুধু ডাটা বানাতে চাইলে

```bash
python build_mix.py --recipe balanced --budget-hours 3 \
    --extra-jsonl myai-dataset.jsonl --output data
# → data/train.jsonl + data/val.jsonl (ভাষা ও সোর্সের হিসাব প্রিন্ট হবে)
```

## ৬. ট্রেনিং শেষে — নিজের কম্পিউটারে চালান

```bash
# ১) Ollama ইনস্টল: https://ollama.com/download
# ২) নামানো .gguf আর Modelfile একই ফোল্ডারে রাখুন
ollama create my-ai -f Modelfile
ollama run my-ai
```

### MY-AI অ্যাপের সাথে যুক্ত করা

Ollama একটা সাধারণ HTTP API দেয়:

```bash
curl http://localhost:11434/api/chat -d '{
  "model": "my-ai",
  "messages": [{"role": "user", "content": "তুমি কে?"}],
  "stream": false
}'
```

MY-AI-এর Node সার্ভার ডিফল্টে **নিজের অফলাইন brain** ব্যবহার করে। এই বড়
মডেলটাকে যুক্ত করতে চাইলে দুটো পথ:

1. **সহজ পথ** — মডেলের উত্তরগুলো Training পেজের চ্যাটে/ইমপোর্টে দিয়ে দিন;
   ছোট brain সেগুলো থেকেই শিখবে।
2. **সরাসরি পথ** — `server/ai/engine.ts`-এ একটা fetch যোগ করে উপরের Ollama
   এন্ডপয়েন্টে কল করুন (Render-এ চালালে আপনার PC-র Ollama-কে
   `ngrok`/Cloudflare Tunnel দিয়ে পাবলিক করতে হবে)।

## ৭. সমস্যা ও সমাধান

| সমস্যা | কারণ | সমাধান |
|---|---|---|
| `CUDA out of memory` | ব্যাচ বড় | `--batch-size 1 --grad-accum 16`, বা `--max-seq-length 768`, বা ছোট মডেল |
| Colab ৩ ঘণ্টায় ডিসকানেক্ট | ফ্রি টিয়ারের সীমা | Drive অন রাখুন → সেল ১–৪ আবার চালিয়ে সেল ৭-এ `--resume` |
| কিছু ডেটাসেট `skipped` | সোর্স গেটেড/রিনেম হয়েছে | সমস্যা নেই, বাকিগুলো দিয়েই মিক্স হয় |
| সব ডেটাসেট skip | ইন্টারনেট/HF ডাউন | Colab রিস্টার্ট করে আবার চালান |
| বাংলা প্রশ্নে ইংরেজি উত্তর | ট্রেনিং কম হয়েছে | `--time-budget-hours 5` বা `--rows 40000` |
| উত্তর একই কথা বারবার | ওভারফিট (একই ডাটা বহুবার) | `--rows` বাড়ান, `--own-repeat 4` করুন |
| GGUF এক্সপোর্ট ফেল | llama.cpp বিল্ড সমস্যা | অ্যাডাপ্টার সেভ হয়েই আছে; পরে আলাদা করে এক্সপোর্ট করুন |
